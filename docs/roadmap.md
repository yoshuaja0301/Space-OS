## Backlog berikutnya (urutan PRD "Urutan backlog pertama" sudah selesai sampai "syscall/IPC serta negative tests")

1. **Storage (D01)**: driver VirtIO block (PCI modern, virtqueue split) sebagai *user-space server* dengan akses MMIO/IRQ lewat capability baru; VFS minimal read-only (FAT dari ESP) → baca file model + verifikasi hash SHA-256 → uji reboot.
2. **Compute ABI v0 (C01)**: objek `MemoryObject` yang dapat di-map dua proses (buffer), layanan `spacecompute` user-space dengan `device_query/buffer_create/buffer_map/queue_create/submit/wait/cancel/release`, contract test versi/invalid handle/batas/unsupported/timeout/cancel.
3. **Inferensi (A01)**: port engine CPU kecil untuk satu arsitektur model, tokenizer, generate 128 token, baseline dipatok.
4. **SMP selesai** (ADR-0024): AP dinyalakan dari MADT, timer local APIC, satu run queue untuk semua CPU. Belum: IOAPIC/MSI, thread ganda (butuh TLB shootdown), dan kepemilikan konsol yang ditegakkan kernel (sekarang antrean masukan global). **Multi-wait dengan batas waktu sudah ada** (`SYS_WAIT_ANY`, ADR-0016) dan dipakai `spacenet`; `spaceshell` belum dipindahkan ke sana dari polling 2 ms-nya.
5. **Penyimpanan yang bisa ditulis** — **kernel selesai** (ADR-0015): FAT32 tulis, `SYS_FS_CREATE`/`SYS_FS_WRITE` di balik hak `FS_WRITE`, dan uji yang menuntut boot kedua menemukan apa yang ditulis boot pertama. Ketiganya sudah dipindahkan ke sana: store paket (P01) dan daftar revokasi (L02) dibuktikan dengan proses kedua yang memuatnya dari disk, dan tambalan agent (G01) dibuktikan dengan `init` yang membaca berkasnya sendiri setelah broker keluar. Yang belum ada di lapisan ini: jurnal, hapus berkas, buat direktori, dan nama panjang.
6. **Jaringan** — **virtio-net dan TCP/IP selesai** (ADR-0016): lease perangkat di balik hak `NET`, `spacenet` dengan DHCP, DNS lewat TCP, klien TCP, dan allowlist per sesi, diuji terhadap layanan lab dan diperiksa di tingkat kabel (pcap). **TLS selesai** (ADR-0017): `SYS_RANDOM` dari virtio-rng atau RDRAND (tanpa cadangan lemah), unit FPU/vektor dimatikan dan setiap build membuktikan tidak ada instruksinya, rustls 0.23 + RustCrypto sebagai pustaka `spacetls`, TLS 1.3 saja, diuji terhadap delapan layanan TLS lab dari sisi guest **dan** sisi server. **Adapter I01 selesai** terhadap penyedia tiruan lab (ADR-0018), diberi label jujur sebagai tiruan sampai ada endpoint sungguhan: yang belum ada untuk itu adalah trust store dengan root CA publik dan jaringan di luar lab.
7. **ARM64 (H02)** — **selesai, di semua CPU** (ADR-0028): `kernel/src/arch/aarch64` (boot EL1, walker page table bersama, vektor exception, GICv3, timer generik, PL011, ECAM, PSCI), profil QEMU `virt` + AAVMF, seluruh suite penerimaan lulus di sana. CPU lain dinyalakan lewat PSCI `CPU_ON`. Keyboard **selesai** lewat USB (xHCI, ADR-0030). Berikutnya: framebuffer (`ramfb`/virtio-gpu), firmware yang berjalan di EL2.
8. **Desktop (U01)** — **selesai untuk keyboard dan framebuffer UEFI** (ADR-0020). Command Center di atas SpaceLink **selesai** (ADR-0022). Pembaruan indeks per berkas **selesai** di SpaceLink (ADR-0023). Berikutnya: pointer (PS/2 mouse atau virtio-input), virtio-gpu dengan damage region, Command Center yang memanggil `UPDATE` saat berkas berubah, pengaturan model, dan `spaceagent` dari Agent Center (yang kini sudah menjalankan `spaceai` sungguhan dengan Stop kooperatif, ADR-0021).
