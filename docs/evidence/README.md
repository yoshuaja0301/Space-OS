# Bukti uji (sesi verifikasi 2026-09-16; diperbarui 2026-09-30 dengan desktop, Agent Center, Command Center, SMP disk SATA/NVMe, kartu Intel e1000 dan recovery, dan 2026-10-05 dengan ARM64)
